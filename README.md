# Airbnb Price Analysis — Bangkok, Thailand

## Project Overview

This project explores factors influencing Airbnb listing prices in Bangkok, Thailand, using R programming, exploratory data analysis, and statistical modeling.

## Research Question

How do room type, guest capacity, and customer demand, measured through reviews, relate to Airbnb listing prices?

## Dataset

The original dataset contained 28,806 Airbnb listings and 79 variables.

## Methods and Techniques

- Data cleaning and preparation
- Exploratory data analysis (EDA)
- Descriptive statistics
- Data visualization
- Multiple linear regression

## Key Findings

Guest capacity demonstrated a stronger relationship with listing prices than the number of reviews.

Although the regression model was statistically significant, it explained only a small portion of price variation, suggesting that additional factors may influence Airbnb pricing.
